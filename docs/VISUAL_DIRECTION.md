# Chromatic visual direction

Review candidate, not a claim of design acceptance or production readiness.

- Midnight and violet landing with a luminous, original exploded-document scene. The scene is a product illustration, not live extraction data.
- Larger editorial heading, restrained pill actions, blue/violet/teal capability surfaces, and a lilac process section create distinct page rhythm.
- Local OFL Geist remains self-hosted. Browser regression verifies that the local font actually loads; no runtime font service is required.
- Three.js adds layered document planes, orbital paths and points. It is lazy-loaded, desktop-only, visibility-paused, pixel-ratio capped and disposed on unmount. CSS document layers and orbital geometry remain without WebGL or with reduced motion. Context loss hides the canvas safely.
- GSAP orchestrates entrance and scroll depth; Framer Motion adds spring CTA feedback. Reduced-motion preference disables the decorative sequences.
- The authenticated app keeps its real data, permissions, API calls, scan/workflow/team controls and semantic status colours. The shell, cards and form surfaces use blue/lilac tints, with richer headers and navigation.
